# 공식 출처와 확인 범위

확인일: 2026-11-05. 아래는 구현 경로 선택의 근거이며 법률 자문이나 모든 접근의 일률적 허가/금지 판정이 아니다. 구현 시점에 변경을 재확인한다.

## S01 — 네이버 API 이관 안내

https://developers.naver.com/notice/article/32530

검색 API 전체 이관과 쇼핑/책/전문자료 검색 종료를 구분한다. 공지에는 쇼핑 검색 등이 2026-07-31 종료되고 NAVER API HUB를 포함한 별도 대체 API가 없다고 명시되어 있다. 검색어 트렌드·쇼핑 인사이트를 상품 최저가 검색과 혼동하지 않는다.

## S02 — 종료 상세 공지

https://developers.naver.com/notice/article/32564

종료 대상과 2026-07-31 적용 일시를 명시한다. 과거 shopping API 문서가 검색된다는 이유로 현재 운영 가능한 것으로 취급하지 않는다.

## S03 — 다나와 이용약관

https://m.danawa.com/info/useTerms.html

가격 정보·상품 정보에 관한 서비스 조건 및 정보 이용 제한·저작권 관련 조항이 포함되어 있다. 특히 회사에 지식재산권이 귀속된 정보의 사전 승낙 없는 영리적 이용 관련 조건을 검토한다. 실제 데이터 종류·용도·계약·운영 요청량을 바탕으로 소스별 이용 범위를 정한다. 해당 페이지 하나만으로 모든 가능한 수집 방법을 일괄 불법이라고 단정하지 않는다.

## 내부 근거

reference/originals의 변경하지 않은 ZIP, reference/handoffs의 기존 문서, reference/verification의 이번 재실행 로그. 코드 상태와 테스트에 관한 최종 근거는 실제 파일과 실행 결과이며 과거 대화의 완성 주장보다 우선한다.
