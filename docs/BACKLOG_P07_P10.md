# Backlog — P07 ~ P10 (GitHub 이슈로 옮길 후보)

마스터 프롬프트의 Phase는 P06에서 끝났다. 아래는 제안이며 범위는 사용자가 정한다. 각 항목을 GitHub 이슈 1개로 만든다.

## P07 · Windows 실기 반영
- 입력: CI `windows` 결과 + 사용자 PC `09_LOGS` + `WINDOWS_ACCEPTANCE.md` 체크 결과
- 완료 기준: install/doctor/smoke/run_once/run_snapshot_demo가 사용자 PC에서 통과, 예약 등록·해제 1회 확인
- 하지 않음: 자동 게시, 무단 예약 등록

## P08 · 실제 다나와 저장본 1개 점검 (P02 A안)
- 입력: 사용자가 직접 저장한 상품 페이지 HTML 1개, 확인 시각(+09:00), 정확한 모델·옵션, 판매자별 결제조건 기록
- 완료 기준: 실제 JSON-LD/판매자 정보 형태를 기록하고, 필요 시 probe를 보완하고, 실제 HTML 기반 회귀 테스트(개인정보 제거본)를 둔다
- 하지 않음: 네트워크 수집, 차단 우회

## P09 · 저장본 작업 파일 작성 화면 (I12)
- 입력: 없음
- 완료 기준: 작업실에서 HTML 파일 선택·확인시각·판매자별 결제조건 입력 → job/meta JSON 저장, 기존 브리지로 실행
- 하지 않음: 자동 체크(사람 확인 플래그 자동 true)

## P10 · 게시 계층 준비 (선택)
- 입력: 플랫폼(Blogger/WordPress 등)과 인증 방식 결정, 사용자 승인
- 완료 기준: 초안(draft) 저장까지, 공개 발행은 별도 승인
- 하지 않음: 네이버 자동 로그인·자동 게시
