# 코딩 세션 준비 자료

## 바로 시작하는 데 필요한 것

이 ZIP과 외부 마스터 MD. 파일 업로드/압축 해제/편집/터미널 Python/결과 다운로드가 가능한 세션을 사용한다. 새 프로젝트나 비공개 저장소를 사용하는 것을 권장하지만 특정 서비스 가입·요금제 변경이 필수인 것은 아니다.

첫 세션은 제공된 합성 데이터로 P00를 시작할 수 있다. 네이버 비밀번호나 API 키는 필요하지 않다. 운영 PC는 Windows에서 최종 설치 시험할 때 필요하다.

## 제공되어 있는 것

- v1.0 원본·소스·스키마·HTML 패널·설치 BAT·테스트.
- v1.3 원본·소스·fixture·가이드·테스트.
- 최초 인계 환경의 31개/19개 테스트 로그와 한계.
- 세션 마스터 프롬프트, 단계 및 검증 기준, 상태 기록 양식.

## 실제 데이터 시험 전 준비할 것

| 자료 | 최소 범위 | 주의 |
|---|---|---|
| 대상 상품 | 정확한 모델 1개 + 색상/용량/옵션 | 광범위한 제품군명만 쓰지 않기 |
| 가격 근거 | 후보 3개, 가격·배송비·결제조건·URL·실제 확인시각 | 테스트값과 실제값 구분 |
| 입력 자료 | 허용된 HTML 저장본·응답·피드 또는 CSV | 계정/토큰/개인정보 제거 |
| 이용 범위 | 소스 및 재사용 조건·확인일·허용 요청량 근거 | 막연한 permission=true로 법적 검토 대체 금지 |
| 상품 이미지 | 직접 제작 또는 사용 가능한 1장과 출처/권한 | 다운로드 가능=재게시 허용 아님 |
| Windows 로그 | doctor/smoke/install 결과 | 비밀정보 제거 후 업로드 |

없는 자료는 없는 상태로 시작한다. 코딩 모델이 실제 가격·허용 API·가입정보를 만들어 채우게 하지 않는다.
