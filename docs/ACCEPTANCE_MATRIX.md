A01 PASS가 A03~A09 PASS를 뜻하지 않는다. 라이브 데이터가 없을 때 전체 자동화 완료라고 표시하지 않는다. ‘입력된 범위의 후보 최저가’와 ‘사이트 전체 최저가’를 구별한다.
