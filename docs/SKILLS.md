# 프로젝트 스킬 목록 (.claude/skills)

이 저장소로 Claude Code를 열면 아래 스킬이 자동으로 인식된다. 요청 문장이 설명과 맞으면 자동으로 쓰이고, `/스킬이름`으로 직접 부를 수도 있다.

| 스킬 | 언제 | 하는 일 | 효과 |
|---|---|---|---|
| `phase-runner` | "P07 수행", "이어서 작업", 인계 ZIP 업로드 | 세션 준비 → 상태 파일만 읽기 → 기준 테스트 → 인수 기준 선언 → 단계별 커밋 → 상태 갱신 → 결과 보고 | 매 세션 시작 크레딧 절감, 1세션 1Phase·STOP 규칙 자동 준수 |
| `price-data-contract` | 가격·URL·시각·표·이미지 코드 수정·리뷰 | 7열 고정, 가격 int/None, 같은 판매자 묶음, 배송비·조건부 가격, observed_at, DEMO 표식, 사람 확인 플래그 규칙 | 오선택(카드 전용 최저가 등)·0원 표시·시각 덮어쓰기 같은 회귀 방지 |
| `qa-verify` | Phase 종료, 코드 변경 후, "검증" | 8개 검사(테스트·doctor·일일 실행·UI QA·E2E·깨끗한 설치·무결성·CI) + 미실행 목록 | 결과를 부풀리지 않는 일관된 보고, 숨은 Windows·패키징 버그 조기 발견 |
| `release-package` | Phase 종료, "ZIP/다운로드/백업" | 매니페스트 → 설치 ZIP → 인계 ZIP → git 번들 → 재해제 검증 → 이어하기 MD → 다운로드 폴더 + 마지막 줄 링크 | 다운로드 안 보이는 문제 재발 방지, 컨테이너 소멸 대비 |
| `danawa-snapshot-onboarding` | 저장한 다나와 HTML 업로드(P08) | 필요한 입력 한 번에 요청 → meta/job 작성 → 오프라인 구조 점검 → 구조 기록 → 익명화 회귀 픽스처 | 실제 페이지 구조 확인을 네트워크 없이 안전하게 진행 |
| `windows-ci-triage` | CI windows 실패, BAT 오류, 한글 깨짐(P07) | 로그 수집 → 증상별 원인표 → 원인 수정 + 재발 방지 테스트 | Windows 문제를 추측 대신 로그 기반으로 빠르게 해결 |
