# 세션에 붙여 넣는 짧은 실행 문구

## 최초 실행 — P00

첨부한 `Naver_Blog_Cloud_Master_Prompt_v1.0.md`와 `Naver_Blog_Cloud_Handoff_v1.0.zip`을 기준으로 구현 작업을 시작해줘.
ZIP의 MASTER_IMPLEMENTATION_PROMPT_KO.md, SOURCE_INVENTORY.json, 00_SESSION 상태 파일부터 읽어줘.
이번 세션은 P00만 실행해줘. 실제 파일·함수·입력 스키마를 확인하고 가용한 테스트를 재실행한 뒤, 다음 통합 작업의 정확한 수정 파일을 정해줘.
v1.1/v1.2 원본이 없다는 사실을 유지하고, 없는 코드를 구현 완료로 간주하지 마.
Windows 실행과 실제 사이트 수집은 수행하지 않았다면 미검증으로 남겨줘.
결과는 갱신 ZIP 1개와 이어하기 MD 1개로 저장하고 P00 종료 후 STOP해줘.

## 다음 실행 — P01 구현

첨부한 최신 체크포인트 ZIP과 이어하기 MD를 기준으로 P01만 구현해줘.
기존 분석을 반복하지 말고 Snapshot→후보별 조건 검증→v1.0 입력→7열 표 연결에 필요한 최소 코드만 수정해줘.
판매자별 배송비·결제조건, 데모 표식, 원래 확인시각, 근거 파일 연결을 유지해줘.
v1.1/v1.2 원본이 제공되었다면 검사해서 연결하고, 없으면 마스터 프롬프트의 직접 어댑터 대안을 새 구현으로 작성해줘. 과거 Add-on 호환이 검증됐다고 표시하지 마.
합성 상품 1개/후보 3개의 E2E와 기존 회귀 테스트를 실행하고 상태를 저장한 뒤 STOP해줘.

## 공통 이어하기 — 하나의 Phase만

이 ZIP이 최신 체크포인트야. MASTER_IMPLEMENTATION_PROMPT_KO.md와 00_SESSION/PHASE_STATUS.json, PHASE_HANDOFF.md를 먼저 읽어줘.
직전 완료 항목을 다시 만들지 말고 다음으로 실행 가능한 Phase 한 개만 진행해줘.
필수 원본이나 실제 소스가 부족하면 그 기능만 blocked로 남겨줘. 실제 코드·테스트 없이 완료로 넘기지 마.
테스트 로그와 변경 파일을 저장하고 ZIP 1개+이어하기 MD 1개로 반환한 뒤 STOP해줘.

## 세션 종료 전 체크포인트

새 작업을 시작하지 말고 현재 변경분을 저장해줘. 진행 중이던 테스트와 미완료 항목을 정확히 구분해줘.
00_SESSION 상태 파일·이슈·실행 로그를 갱신하고, 다음 세션에서 바로 이어갈 실행 명령까지 넣어줘.
다운로드 가능한 최신 ZIP과 이어하기 MD를 생성한 뒤 종료해줘. 크레딧 잔량이나 나중에 완료할 작업을 추측하지 마.

실제 사용자 설정·데이터를 보존하고 변경분·회귀 테스트·체크포인트를 남겨줘.
