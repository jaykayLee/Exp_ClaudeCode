# 신규 콘텐츠 설계 예시

제안 제목: 표시 최저가보다 먼저 확인할 세 가지: 모델·배송비·확인시각

이는 독창적으로 작성한 구성 예시이며 실제 제품 리뷰나 현재 가격 보고가 아닙니다.

## 도입부 예시
상품명만 같다고 같은 구매 조건인 것은 아닙니다. 이 글에서는 모델과 옵션, 배송비와 할인 조건, 가격 확인시각을 구분해 비교하려고 합니다. 검증되지 않은 가격은 최저가로 단정하지 않고 확인되지 않은 부분을 남깁니다.

## 새 목차와 필요한 근거
1. 이 비교가 해결하려는 질문 — 독자의 구매 고민을 한 문장으로 정의.
2. 같은 제품의 범위 — 모델번호, 용량, 색상, 구성, 신품 여부를 직접 확인.
3. 조건을 맞춘 7열 표 — 사이트별 URL·실제 확인시각·가격 비교 조건을 기록.
4. 숫자 밖의 조건 — 배송비, 카드, 쿠폰, 설치비, 해외 배송 여부 중 실제 확인한 항목만 설명.
5. 누구에게 어떤 조건이 맞는가 — 나의 선택 기준과 검증된 한계를 분리.
6. 미확인 사항과 다음 확인 — 확인하지 못한 사양이나 가격을 숨기지 않음.

## 직접 사용하지 않은 경우
“직접 써 보니”라고 쓰지 않습니다. “공개 사양과 확인한 구매 조건을 비교한 정보 글”로 표시합니다.
