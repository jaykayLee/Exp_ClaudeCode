# 새 콘텐츠 작성 지침 — 입력 근거 기반

목표: 다른 글의 표현을 재작성하는 것이 아니라, 내 독자의 질문에 내 근거로 답하는 새 글을 설계한다.

입력: 독자, 질문, 검토된 상품 데이터, 확인시각, 비교 조건, 직접 확인한 사실/측정/경험, 참고 URL, 이미지 권리, 광고/협찬/제휴 관계.

처리:
1. 참고 자료에서 사실·의견·일반적인 작성 원칙을 분리한다. 사실은 제조사나 공식 자료로 다시 확인한다.
2. 나의 직접 경험이 없으면 후기라고 쓰지 않는다. 수치, 실제 사용, 구매, 테스트 결과를 만들지 않는다.
3. 질문 중심의 새 목차를 작성한다. 다른 글의 문장·고유한 배열·사진을 그대로 사용하지 않는다.
4. 동일 모델/옵션, 배송비/카드/쿠폰 조건, 실제 확인시각을 함께 설명한다. 전체 시장의 절대 최저가라고 단정하지 않는다.
5. 추천/비추천 대상·한계·미확인 사항을 적는다. 협찬·제휴 여부는 확인된 사실대로 표시한다.
6. 출처 표기는 허락·권리·사실검증을 대신하지 않는다. 이미지 재게시 범위를 별도 검토한다.
7. DEMO_ONLY 또는 HOLD 자료는 공개하지 않는다. 형식 검사 통과 후에도 사람이 최종 검토한다.

결과: 새 제목 후보 3개, 새 목차, 각 문단의 근거 매핑, 누락 근거 목록, 검토할 이미지/출처/이해관계 항목.
외부 AI 호출이나 자동 게시를 이 프롬프트로 자동 승인하지 않는다.
