# 확장 모듈 계약

작은 기능 변경 때문에 전체 프로젝트를 다시 만들지 않습니다. 새 수집기/발행기는 독립 ID·버전·코어 호환성·권한·설정·테스트를 등록하고 기본적으로 비활성화합니다.

가격 수집기: `03_PROVIDERS/providers/base.py`의 PriceProvider와 PriceCandidate 계약을 구현합니다. 검색 전 모델·옵션을 확정하고 가격 범위·URL·확인시각을 반환합니다. 403/429·CAPTCHA·파싱 실패는 명시적 상태로 반환하며 우회하지 않습니다.

발행기: `05_PUBLISHERS/publishers/base.py`의 prepare/publish를 분리합니다. 초안·이미지 업로드·인증·게시 승인·중복 방지·취소를 별도 검증합니다. 현재 publish는 모두 미구현입니다.

외부 API 자격증명은 서버 측 비밀 저장소를 별도로 설계합니다. HTML, JSON 샘플, 로그, ZIP에 실제 키·비밀번호·쿠키를 포함하지 않습니다. 향후 API 설치에도 BAT 진입점을 제공합니다.

이 디렉토리는 모듈 계약과 등록 장소입니다. v1.0에서 임의 플러그인을 자동 탐색·설치·실행하는 로더는 제공하지 않습니다.
