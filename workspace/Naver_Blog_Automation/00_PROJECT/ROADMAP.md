# 다음 진행 기준

주차가 바뀌었다고 완료 처리하지 않습니다. 사용자 PC 실행 로그와 실제 테스트 증거가 기준입니다.

1. Windows: install → start_panel → 데모 3행 → smoke. 실제 PC 환경 결과 확인 전 Windows 설치 검증 완료라고 말하지 않습니다.
2. Danawa: 정확한 모델 3개, 허용되고 안정적인 접근/제공 경로와 데이터 이용 범위를 확인한 뒤 live 어댑터 구현. 3회 반복 시 동일상품·가격·URL·확인시각·부분 실패 검증.
3. Naver Shopping: 종료된 Shopping Search API를 제외한 허용된 경로 확정 후 구현. 없으면 수동 가져오기 유지. API HUB의 다른 서비스를 상품 최저가 검색의 대체 API로 혼동하지 않습니다.
4. 통합: 하루 실행, 부분 실패, 가격 유효기간, 이미지 권리, 표 생성 회귀 검증.
5. 발행: 가능한 공식/허용된 연계 수단을 확인하고 초안·이미지·승인·중복 방지부터 구현. 초기 버전에서 자동 공개 발행 금지.
6. 플랫폼 확장: 네이버 수집과 게시를 분리하여 Blogger/WordPress 발행 어댑터 추가.

이번 주 작은 목표: 내 Windows에서 테스트 3행과 실제 상품 1행의 로컬 자료 생성.
주요 blocker: 자동 가격 수집에 쓸 허용되고 안정적인 데이터 경로.
