# 배포 검증 범위와 한계

1. Python 오프라인·로컬 HTTP 테스트: 31개. 테스트마다 임시 워크스페이스를 생성하며 실제 가격 사이트나 계정에 접속하지 않음.
2. 이전 v0.4 원본 ZIP: CRC 검사와 원래 단위 테스트 2개 통과. 원본을 변경하지 않음.
3. Chromium/Playwright UI: 15개 검사. 데스크톱 1440x1000, 모바일 390x844 렌더링, 상품·이미지·상태·JSON·브리프·설정·내부 링크 검사.
4. 이 컨테이너의 브라우저는 URL 직접 탐색이 정책으로 제한됨. HTML은 set_content로 렌더하고 UI API 요청은 명시적인 테스트 브리지로 실제 로컬 Python HTTP 서버에 전달함. 네이티브 Windows 브라우저에서의 URL 접속 검증과 다름.
5. BAT/PowerShell은 파일 인코딩·줄바꿈·참조·구성 검토. Windows에서 실제 설치/예약 실행은 수행하지 못함.
6. 이미지 다운로드는 모의 응답/차단 검증. 실제 외부 이미지 호스트 연결은 미검증.
7. Danawa/Naver live 가격 수집, Naver 계정/편집기/공개 발행, Blogger/WordPress API 연동은 미구현 또는 미검증.

배포 검증 로그는 이 QA 폴더, 사용자 PC 실행 결과는 09_LOGS에 저장합니다.
