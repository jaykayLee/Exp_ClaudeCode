# 네이버 블로그 수동 게시 준비

상태: DEMO_ONLY

데모 가격·제품·링크입니다. 실제 시세와 관계없으며 게시할 수 없습니다.

1. product_table.html의 모델·옵션·가격 확인시각·배송비 조건을 검토합니다.
2. images/ 파일의 사용 권한과 출처를 확인합니다.
3. 네이버 블로그에서 직접 로그인하고 새 글을 작성합니다. 계정 비밀번호를 프로그램에 입력하지 않습니다.
4. 본문은 별도 콘텐츠 브리프로 작성하고 이미지는 에디터로 업로드합니다. HTML의 base64 이미지는 게시 URL이 아닙니다.
5. 에디터가 표 붙여넣기를 보존하는지 먼저 1개 행으로 시험합니다. 보존하지 않으면 에디터의 표 도구로 구성합니다.
6. 모바일/PC 미리보기를 확인하고, 직접 공개 범위와 발행을 결정합니다.

이 폴더는 업로드 준비 자료이며 네이버 서버의 임시저장 글이 아닙니다.
실시간 가격 갱신과 자동 게시 어댑터는 구현되지 않았습니다.
