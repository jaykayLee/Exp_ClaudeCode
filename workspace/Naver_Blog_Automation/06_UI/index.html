02 / SETUP

처음 사용하는 PC에서 설치하기

권장 환경은 Windows 11 x64와 Edge 또는 Chrome입니다. 별도 개발 도구를 먼저 설치할 필요는 없습니다.

관리자 권한 설치를 기본으로 요구하지 않음

필요한 프로그램

항목처리 방법
Python3.11~3.13 x64 탐지. 없으면 동의 후 3.13 계열 설치 시도.
Pillow 12.3.0프로젝트 전용 .venv에 BAT가 설치.
PowerShellWindows 기본 5.1 사용. WinGet 실패 시 서명 확인한 공식 Python 설치 파일 사용.
브라우저현재 사용하는 Edge/Chrome. Node.js·Docker·Office·Selenium은 불필요.

Python 3.13은 이 프로젝트의 호환성 기준이며 “가장 최신 버전”이라는 의미가 아닙니다. 의존성 목록은 내부 tools/dependencies.lock으로 관리합니다. [S4] [S5] [S6]

설치 전 확인

체크 표시는 브라우저에 저장하는 개인 메모입니다. 설치 또는 테스트 통과를 증명하지 않습니다. 새 PC에서는 다시 확인하세요.

1

ZIP 해제 → install.bat 더블클릭

프로젝트의 가장 바깥 폴더에서 실행합니다. Python이 없다면 Install Python ... [Y/N] 질문에 설치 동의 시 Y를 입력합니다. 설치기는 WinGet → python.org 서명 검증 설치 순서로 시도합니다. 기존 Python과 다른 프로젝트의 패키지를 덮어쓰지 않고 이 폴더의 가상환경을 사용합니다.

인터넷 연결이 필요합니다. 회사 보안 정책으로 차단되면 우회하거나 백신·TLS 검사를 끄지 말고 관리자에게 로그를 전달합니다. BAT의 PowerShell 실행 정책 지정은 해당 프로세스에만 적용하며 시스템 정책을 영구 변경하지 않습니다.

2

설치 결과 확인 → start_panel.bat 더블클릭

설치 마지막에 Setup completed를 확인합니다. 평소에는 이 실행 파일 하나만 사용합니다. Python 서버와 브라우저가 함께 열립니다. 기본 주소는 http://127.0.0.1:8765입니다.

검은 실행 창은 서버이므로 사용 중 닫지 않습니다. 종료할 때 창에서 Ctrl+C를 누릅니다. 방화벽 공개 허용·공유기 포트 개방은 필요하지 않습니다. 다른 기기에서 접속하는 사이트가 아닙니다.

3

아래 작업실에서 데모 3개 → Python 검증 · 표 생성

우측 상단이 로컬 서버 연결인지 확인합니다. 테스트 자료 3개의 표와 이미지를 먼저 생성한 뒤 실제 상품을 입력합니다. HTML 파일을 직접 연 경우 설명·브리프 생성·입력 연습은 가능하지만 Python 저장·이미지 변환·출력은 연결되지 않습니다.

설치 실패 시 실행 순서doctor.bat는 Python·Pillow·폴더·설정 상태를 점검합니다. smoke.bat는 오프라인 자동 테스트를 실행합니다. 상세 원인은 09_LOGS/install_*.log, doctor_report.json, test_report.json에서 확인합니다. 설치가 완전히 끝나기 전에는 다음 단계로 넘어가지 않습니다.

폴더를 눌러 역할 확인

00_PROJECT — 프로젝트 기준과 인계

PROJECT_CONTEXT · MANIFEST · LOCK · REGISTRY에 구현 범위, 독립 모듈, 테스트 상태, 다음 과제를 기록합니다. LOCK은 기준 버전 파일이며 실행 동시성 잠금과는 다릅니다.

01_CONFIG — 설정은 코드와 분리

settings.example.json은 배포 기본값, settings.local.json은 사용자 PC 설정입니다. 재설치해도 기존 사용자 설정은 보존합니다. 이미지 크기는 패널에서 저장할 수 있습니다. 비밀번호나 인증 키를 HTML에 넣지 않습니다.

02_CORE / 03_PROVIDERS / 05_PUBLISHERS

공통 데이터 처리·수집·발행의 경계를 분리합니다. 수집기가 표를 만들거나 발행기가 가격을 임의로 고치지 않도록 인터페이스를 고정합니다. 현재 실수집 및 원격 발행 메서드는 명시적인 미구현 오류를 반환합니다.

04_CONTENT — 재생산의 근거 보관

references에는 작성자·URL·확인일·참고한 일반 원칙을, briefs에는 내 자료로 구성한 새 글 설계를 보관합니다. 타인의 글 전문을 모아 단어만 바꾸는 저장소가 아닙니다.

07_DATA — 운영 입력과 데모 분리

inbox/products.json은 실제 처리할 입력 파일입니다. samples는 테스트 전용이며 자동으로 운영 데이터에 섞이지 않습니다. images/original은 원본, images/resized는 변환본, state는 마지막 실행과 잠금 상태입니다.

08_OUTPUT / 09_LOGS / 12_BACKUP

실행별 HTML·이미지·정규화 JSON·검토 보고서·네이버 전달 가이드를 생성합니다. 동일 날짜·동일 입력·동일 이미지 설정은 같은 경로를 재사용합니다. 이전 v0.4 ZIP은 수정하지 않고 보관합니다.

04 / PRICE SOURCES

최저가보다 먼저, 같은 상품인지 확인

우선순위는 다나와 → 네이버쇼핑 → 이미지 → 출력 표입니다. 접근 경로가 미확정이면 검토 기반만 먼저 실행합니다.

대상이번 버전의 동작자동 수집 전 확인
다나와직접 확인한 값 입력·JSON 가져오기. Live Provider는 미연결.허용된 접근 방법·데이터 이용 범위 확인 후 정확한 모델 3개 검증. 이용약관은 상업적 복제·이용 관련 조건을 포함하므로 원문을 확인합니다. 모든 수집이 일률적으로 금지됐다고 단정하지 않습니다. [S2]
네이버쇼핑사용자 입력·승인된 별도 데이터 경로 가져오기. 종료된 검색 API는 호출하지 않음.허용된 대체 데이터 경로를 별도로 확보해야 합니다. 옛 API 키 발급을 설치 전제조건으로 삼지 않습니다. [S1]
가격 선정양의 정수 또는 미수집. 최저가의 근거는 사용자 검토 기록.모델번호·용량·색상·구성품·신품/중고·렌탈 여부·배송비·카드·쿠폰 조건을 일치시킵니다. 검색 전체의 가장 작은 숫자를 바로 최저가로 쓰지 않습니다.

지금 직접 입력하는 방법

일반 브라우저에서 제품을 확인하고, 정확한 모델번호와 옵션을 적습니다. 각 사이트에서 확인한 가격·해당 URL·확인시각·비교 조건을 입력합니다. 비슷한 제품이나 액세서리를 걸러낸 뒤 동일 상품 확인에 체크합니다.

현재 프로그램은 입력한 숫자가 실제 최저가인지 자동 증명하지 않습니다. 링크 형식 검사는 해당 페이지의 존재나 가격 일치 여부 검사와 다릅니다.

막히면 멈추는 수집기 계약

향후 실제 어댑터는 요청 횟수·타임아웃·캐시·확인시각을 기록해야 합니다. CAPTCHA, 접근 거부 또는 호출 제한에 대해 우회·계정 공유·무한 재시도를 구현하지 않습니다.

06 / IMAGE PIPELINE

원본을 보존하고, 비율을 유지합니다

상품을 잘라내거나 늘리지 않고 흰색 캔버스 중앙에 배치합니다. EXIF 방향과 투명 배경을 처리합니다.

증명사진형 프로젝트 프리셋

354×472px / 300dpi는 약 3×4cm에 해당하도록 잡은 프로젝트용 선택값입니다. 네이버 공식 규격이나 신분증 제출 규격이 아닙니다. 웹 화면 크기는 DPI 메타데이터가 아니라 픽셀·표시 스타일로 결정됩니다.

설정을 바꾼 뒤 표를 다시 생성하면 새 규격을 적용합니다. 원본은 덮어쓰지 않습니다. 구현은 Pillow의 이미지 처리 기능을 사용합니다. [S6]

이미지 URL 다운로드는 선택 기능

기본은 꺼짐입니다. HTTPS · 정확한 호스트 목록 · 공인 IP · 8MiB/2,000만 픽셀 한도만 허용합니다. 리디렉션도 다시 검사하며 403/429를 우회하지 않습니다. 비공개 네트워크 주소는 차단합니다.

사진을 볼 수 있다는 사실과 재게시 권한은 다릅니다. 직접 촬영한 이미지, 이용 범위를 확인한 라이선스 이미지, 명시적으로 허락받은 이미지만 선택합니다. 출처 입력은 이용 허락 자체를 대신하지 않습니다.

09 / OPERATIONS

일일 운영은 검토부터 자동화

매일 파일을 재생성하는 것과 매일 최신 가격을 수집하거나 글을 게시하는 것은 다릅니다.

선택: 하루 한 번 로컬 검토

실제 운영 입력을 저장한 뒤 enable_daily_review.bat를 실행합니다. 실행 시각을 HH:mm으로 입력하고 등록 확인에 동의해야 Windows 작업 스케줄러에 등록됩니다. 설치만으로 예약되지는 않습니다. 예약 등록은 Windows ScheduledTasks 기능을 사용합니다. [S7]

현재 예약은 저장된 입력의 유효성 검토·이미지 변환·표 생성만 수행합니다. 가격이 오래되면 보류하고 확인시각을 오늘로 바꾸지 않습니다. 해제는 disable_daily_review.bat입니다. 폴더를 이동했다면 기존 예약을 해제하고 새 경로에서 재등록합니다.

백업과 업데이트 원칙

서버·예약 실행을 멈추고 01_CONFIG, 04_CONTENT, 07_DATA, 필요한 08_OUTPUT을 백업합니다. .venv는 재설치할 수 있으므로 일반적인 소스 배포 ZIP에 넣지 않습니다.

업데이트는 새 폴더에 먼저 풀어 smoke.bat 검증 후 필요한 입력·설정만 옮깁니다. 사용자 데이터를 한 번에 삭제하는 초기화 스크립트는 제공하지 않습니다.

타인에게 배포할 때 사용자 입력·사진·로그·인증 정보는 제외합니다. 예약 작업의 실제 등록 상태는 Windows 작업 스케줄러가 기준이며 이 HTML의 체크 메모와 다릅니다.
