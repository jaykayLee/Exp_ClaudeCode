# 미해결 사항

| ID | 우선순위 | 상태 | 문제와 다음 조치 |
|---|---|---|---|
| I01 | P0 | BLOCKED_INPUT | v1.1/v1.2 원본 미확보. 원본 추가 시 검사하거나 새 직접 어댑터를 사용한다. |
| I02 | P0 | OPEN | v1.3 최상위 배송비/결제조건을 모든 후보에 공통 적용. 후보별 근거로 분리한다. |
| I03 | P0 | OPEN | Snapshot 출력과 v1.0 입력은 다르다. 변환 및 E2E 테스트가 필요하다. |
| I04 | P0 | BLOCKED_EXTERNAL | 다나와 운영 데이터 경로·이용 범위가 확정되지 않았다. 작은 live pilot 전 확인한다. |
| I05 | P1 | BLOCKED_EXTERNAL | 네이버쇼핑 종료 API를 대체할 실제 허용 경로 미확정. 쇼핑 인사이트와 혼동하지 않는다. |
| I06 | P1 | NEEDS_WINDOWS_CHECK | BAT 설치·일일 예약은 실제 Windows 로그가 필요하다. |
| I07 | P1 | OPEN | DEMO_ONLY를 끝까지 보존하면서 E2E 테스트할 하네스 필요. 기존 CSV 출력 차단을 완화하지 않는다. |
