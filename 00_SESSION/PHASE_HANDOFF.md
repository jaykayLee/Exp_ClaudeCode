# 이어하기 상태 — 시작 전

현재 요청 범위는 구현용 프롬프트·자료 준비다. P00~P06의 클라우드 구현을 대신 완료한 것이 아니다.

## 확보한 것
v1.0 원본과 v1.3 원본, 각각의 독립 재실행 로그, 최소 작업용 디렉토리.

## 첫 실행
MASTER_IMPLEMENTATION_PROMPT_KO.md를 읽고 P00만 수행한다. 파일과 스키마·호환 여부를 확인하고 기존 테스트를 현재 세션에서 재실행한다. 결과를 남긴 후 STOP한다.

## 다음 P01 핵심
Snapshot의 개별 후보에 배송비·결제조건·근거를 연결하고 기존 v1.0 입력 및 표로 전달한다. 누락 v1.1/v1.2는 추측하지 않는다. 직접 연결 대안을 새 코드로 구현할 수 있다.
