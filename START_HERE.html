01 · 먼저 올릴 두 파일

Naver_Blog_Cloud_Master_Prompt_v1.0.md + Naver_Blog_Cloud_Handoff_v1.0.zip

파일 편집·터미널 실행·결과 다운로드가 가능한 코딩 세션에 올린 뒤 아래 문구를 사용합니다. 특정 서비스의 크레딧 수치나 모델은 전제하지 않습니다.

첨부한 마스터 MD와 ZIP을 기준으로 P00만 실행해줘.
실제 파일·스키마·테스트를 확인하고 다음 통합 작업의 수정 지점을 정해줘.
v1.1/v1.2 원본은 누락 상태로 유지해줘.
실행 증거와 체크포인트를 ZIP 1개+이어하기 MD 1개로 저장하고 STOP해줘.

04 · 지금 확인할 핵심

v1.3은 배송비와 결제조건을 최상위 메타데이터에서 모든 후보에 공통 적용합니다. 판매자마다 조건이 다른 경우를 먼저 테스트해야 합니다.

119,000+0 / 117,000+5,000 / 카드 전용 80,000이라는 합성 사례에서 일반 구매 최저가는 첫 후보여야 합니다.

05 · 세션에 올리지 않을 것

네이버 비밀번호, 로그인 쿠키, 개인 브라우저 프로필, 실제 API 키, 전체 환경 폴더(.venv)는 제외합니다.

허용된 상품 자료와 사용 가능한 이미지, 비밀정보를 제거한 Windows 로그만 추가합니다.

06 · 중단해도 이어가기

Phase 종료마다 00_SESSION의 상태·이슈·실행 결과를 갱신합니다. 다음 세션에는 가장 최근 ZIP과 이어하기 MD를 올립니다. 처음 제공한 패키지로 되돌아가지 않습니다.

준비된 원본은 reference/originals, 수정할 코드는 workspace/Naver_Blog_Automation입니다. verify_handoff.bat는 최초 배포 무결성만 확인하며 앱을 설치하거나 게시하지 않습니다.

입력 자료 체크리스트 · 인수 기준 · 공식 출처

필수 열: No. | 상품명 | 이미지 | 다나와 최저가 | 사이트 주소 | 네이버 최저가 | 사이트 주소
자동 발행·공개 배포·유료 호출은 기본 비활성화입니다. Linux 테스트 통과를 Windows·실제 사이트 검증으로 바꾸어 표현하지 않습니다.
